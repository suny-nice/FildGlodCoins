### 1.项目简介

	翻金币项目是一款经典的益智类游戏，我们需要将金币都翻成同色，才视为胜利。首先，开始界面如下：

<img src= "FildGlodCoins/res/image01.png" alt="img" width="40%" height="40%"/>

点击start 动态按钮，进入下层界面，选择关卡：

<img src= "FildGlodCoins/res/image02.png" alt="img" width="40%" height="40%"/>

在这里设立了20个关卡供玩家选择，假设我们点击了第1关，界面如下：

<img src= "FildGlodCoins/res/image03.png" alt="img" width="40%" height="40%"/>

如果想要赢取胜利，我们需要点击上图中红色方框选取的区域，翻动其上下左右的金币，然后当所有金币都变为金色，视为胜利，胜利界面如下：

<img src= "FildGlodCoins/res/image04.png" alt="img" width="40%" height="40%"/>
